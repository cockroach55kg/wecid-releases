# Исходники сторонних компонентов под MPL

WECID содержит сторонние библиотеки, для которых действует Mozilla Public
License 2.0 (MPL). Их исходники доступны бесплатно по ссылкам ниже.
Это исходники отдельных библиотек, а не закрытый код самого WECID.
Условия WECID не ограничивают права, предоставленные MPL на эти компоненты.

Версии соответствуют текущему Cargo.lock. Архивы включают исходники,
их уведомления и лицензии. Дополнительная установка этих библиотек
для обычного использования WECID не требуется.
