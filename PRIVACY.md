# Как WECID хранит и передаёт данные

Здесь описано поведение текущего кода приложения. У старых предварительных
сборок часть возможностей, например проверка обновлений, может отсутствовать.

## Работа на одном компьютере

Для ведения задач регистрация не нужна. Задачи, колонки и связанные с ними
данные хранятся на компьютере, в базе SQLite — отдельном файле приложения.
Резервная копия сохраняется в выбранном вами месте. Выбранный фон копируется
во внутреннюю папку WECID.

Синхронизация и Telegram включаются по желанию. Без них данные задач
не передаются серверу WECID. Это не означает полного отсутствия сетевых
запросов: в сборке с подключёнными обновлениями проверяется новая версия.

## Синхронизация между устройствами

При включении синхронизации на сервер Supabase передаются:

- задачи, описания и колонки;
- сроки, напоминания, повторения и отметки выполнения;
- теги и списки подзадач;
- служебные идентификаторы устройств и записи об изменениях.

Это необходимо, чтобы ваши устройства получали одинаковые данные.
Отдельная учётная запись WECID, почта и пароль не требуются.

Доступ каждого устройства защищён секретным ключом — Device Token.
Код группы — Sync Code — позволяет подключить ещё одно устройство;
его можно заменить. Ключ устройства и код группы сохраняются в системном
защищённом хранилище учётных данных. Не передавайте код группы посторонним.

## Telegram

Если вы подключаете бота, сервер получает идентификаторы пользователя
и чата Telegram для связи с вашей группой синхронизации. Задачи, созданные
или показанные в боте, и содержимое уведомлений передаются через сервис
Telegram Bot API. Подключать Telegram для локальной работы необязательно.

## Проверка обновлений

В сборке с подключённым механизмом обновлений при запуске главного окна
запрашивается файл со сведениями о новой версии на GitHub. Данные ваших
задач не включаются в этот запрос. Скачивание пакета начинается только
после вашего действия в настройках; установка подтверждается отдельно.
После полного выхода WECID не проверяет обновления.

## Что происходит при отключении

Отключение Telegram отзывает связанный с ним служебный доступ и прекращает
новые уведомления. Если отозвать устройство в синхронизации, оно больше
не сможет обращаться к данным группы на сервере.

Отключение не удаляет все ранее переданные данные с сервера немедленно.
Отдельной функции полного удаления группы и её данных с сервера
в текущей версии нет.

## Сведения об ошибках

Серверные функции могут сохранять технические сведения о запросах
и ошибках. Секретные ключи и коды доступа не должны попадать в сообщения
пользователям или публичные файлы проекта. При обращении за помощью
не прикладывайте их к сообщению или снимку экрана.
