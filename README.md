# WECID — задачи и напоминания

WECID (What Else Can I Do — «Что ещё я могу сделать?») помогает держать дела
на одной доске: создавать задачи, распределять их по колонкам и не забывать
о сроках. Для работы на одном компьютере регистрация не нужна.

Приложение готовится к первому полноценному выпуску 1.0. Сейчас доступны
предварительные сборки, которые передаются отдельно. В публичном
[разделе загрузок](https://github.com/cockroach55kg/wecid-releases/releases)
пока нет опубликованного выпуска.

## Что умеет WECID

- Создавать задачи с описанием, сроком, приоритетом, тегами и списком подзадач.
- Распределять задачи по колонкам и переносить карточки мышью.
- Показывать просроченные дела, искать задачи и отбирать их по условиям.
- Напоминать о задачах и повторять дела по расписанию.
- Менять цвета и фон доски, переключать обычный и компактный вид карточек.
- Открывать ссылки из описания задачи в браузере.
- Сохранять резервную копию и восстанавливать из неё данные.
- По желанию синхронизировать задачи между компьютерами.
- По желанию подключать Telegram: WECID Bot для работы с задачами,
  WECID Alerts для напоминаний.

## Загрузка и установка

После публикации установщики будут доступны в
[Releases — разделе выпусков](https://github.com/cockroach55kg/wecid-releases/releases).
Внутри выпуска откройте список файлов **Assets** и выберите файл для своей
системы. Если предварительная сборка уже получена отдельно, используйте
инструкцию ниже. В именах файлов вместо `<версия>` будет номер, например `0.1.0`.

Для обычной установки нужны только `.exe` или `.dmg`.
Файлы `.sig`, `.app.tar.gz` и `latest.json` предназначены для механизма
обновлений — вручную устанавливать их не нужно.

### Windows

1. Выберите `WECID_<версия>_x64-setup.exe` для 64-разрядной Windows.
2. Запустите файл и следуйте шагам установщика. Он устанавливает приложение
   для текущего пользователя, без запроса прав администратора.
3. Откройте WECID из меню «Пуск» или ярлыка.

У приложения нет коммерческого сертификата подписи, поэтому Windows может
предупредить о неизвестном издателе. Продолжайте установку только если
доверяете источнику файла; отключать защиту Windows целиком не нужно.

### macOS

1. Откройте меню Apple → «Об этом Mac» и посмотрите тип процессора:
   **Apple M-серии** — нужен `WECID_<версия>_aarch64.dmg`,
   **Intel** — `WECID_<версия>_x86_64.dmg`.
2. Откройте `.dmg` и перетащите WECID в папку «Программы».
3. Откройте WECID из папки «Программы». Образ диска после копирования можно извлечь.

Приложение не заверено Apple, поэтому при первом запуске macOS может
показать предупреждение. Если файл получен из доверенного источника,
после попытки запуска откройте «Системные настройки» → «Конфиденциальность
и безопасность» и подтвердите открытие WECID. Название кнопки зависит
от версии macOS. Подробнее — в
[инструкции Apple](https://support.apple.com/ru-ru/102445).
Не отключайте защиту всей системы и не игнорируйте сообщение об обнаруженном
вредоносном ПО.

### Linux

Готовый установщик для Linux пока не подготовлен и не опубликован.
Поэтому сейчас нет подтверждённой инструкции установки WECID на Linux.
Файлы Windows и macOS для этой системы не подходят. Проверка части кода
на Linux не означает готовность Linux-версии приложения.

## Первое использование

При первом запуске выберите, что должно происходить при закрытии окна:
полный выход или работа в трее — области со значками приложений около часов.
По умолчанию выбран полный выход. Там же можно настроить запуск WECID
вместе с системой; эти параметры можно поменять позже в настройках.

Создайте колонку, добавьте задачу и укажите срок. При необходимости задайте
напоминание, повторение, теги или подзадачи. Готовые дела можно отмечать
выполненными и возвращать в работу.

Системные напоминания работают, пока WECID запущен, в том числе в трее.
После полного выхода они не приходят. Telegram подключается отдельно;
его сообщения доставляются через сервер, а не через запущенное окно WECID.

## Обновления

Подготовлен механизм проверки новой версии при запуске и небольшое окно
с описанием изменений. Скачивание и установка происходят только по выбору
пользователя в настройках → «О приложении»; автоматического скачивания нет.
После полного выхода WECID не проверяет обновления.

Первый публичный выпуск ещё не опубликован, поэтому канал обновлений пока
недоступен. Подготовка механизма не означает, что обновление уже можно скачать.
Подпись пакетов обновлений проверяет их подлинность; она не заменяет
сертификаты Windows или Apple и не отменяет предупреждения системы.

## Данные

Основные данные сохраняются на компьютере. Синхронизация и Telegram
необязательны; при их включении нужные для работы данные передаются
соответствующим сервисам. В сборках с подключённым механизмом обновлений
при запуске также запрашиваются сведения о версии на GitHub.

## На чём сделано приложение

- **Tauri 2 и Rust** — окно приложения, связь с системой и установщики.
- **React и TypeScript** — интерфейс и поведение элементов.
- **SQLite** — база данных на компьютере.
- **Supabase и PostgreSQL** — серверная часть синхронизации и Telegram.
- **Telegram Bot API** — обмен сообщениями с ботами.
- **Vite** — инструмент сборки интерфейса.

Исходный код хранится отдельно, в закрытом репозитории. Публичное хранилище
предназначено для установщиков, обновлений и пользовательской документации.
