# WECID — сборки и обновления

Здесь размещаются установщики WECID и подписанные пакеты обновлений.
Исходники приложения хранятся в отдельном закрытом репозитории.

Доступные версии появятся в разделе «Releases» после публикации.
Пока ни одна версия в этом хранилище не опубликована.

WECID проверяет наличие обновлений при запуске. Скачивание и установка
выполняются только по отдельным действиям пользователя в настройках.

Пакеты обновлений проверяются по цифровой подписи. Это не платный
сертификат Windows/macOS; операционная система может предупреждать
о неизвестном разработчике.
